# Braking Lab Race Engineer 0.1.1 — piloto privado

Actualización editorial y de empaquetado del piloto 0.1.0. Las nueve skills y la URL del MCP no cambiaron. Los README explican los límites comprobados y las guías apuntan directamente a los archivos de esta versión. Los ZIP ya no incluyen un README con enlaces relativos a documentos ausentes.

## Archivos

- `braking-lab-claude-0.1.1.zip`: plugin de Claude con nueve skills y una conexión MCP.
- El ZIP de ChatGPT contenía una app personal del piloto y se retiró antes de abrir el repositorio al público; no era instalable por terceros.
- `braking-lab-portable-0.1.1.zip`: Agent Plugins con nueve skills y configuración MCP.
- `SHA256SUMS`: huellas de los dos ZIP disponibles.

La importación y las consultas autenticadas se probaron con 0.1.0. En 0.1.1 se verificaron los manifiestos, las nueve skills, la construcción de los ZIP, sus huellas y el plugin de Claude extraído. Esta es una versión histórica del piloto; para instalar públicamente usa 0.2.0.
