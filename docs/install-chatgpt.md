# Race Engineer en ChatGPT

La ficha pública de ChatGPT está pendiente de la verificación del desarrollador, la preparación del MCP para la revisión y la aprobación de OpenAI. El instalador de terminal de este repositorio sirve para agentes locales; no instala un plugin en ChatGPT web.

El archivo de prueba de ChatGPT `v0.1.1` correspondía a una conexión personal y no es una vía de instalación pública. Cuando exista una ficha aprobada, esta guía enlazará a ella y explicará cómo autorizar la cuenta de Braking Lab. No descargues el ZIP del piloto para intentar conectar otra cuenta.

Mientras tanto, puedes usar el Race Engineer en [Claude Code, Codex u otro agente local](install-cli.md) con el MCP `https://mcp.brakinglab.com/mcp` y tu propia cuenta de Braking Lab.
