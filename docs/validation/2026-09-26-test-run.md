## Juicio

El empaquetado y la instalación privada de 0.1.1 están comprobados. El soporte
funcional completo definido en [`../test-plan.md`](../test-plan.md) todavía no
está validado: faltan el corpus de Claude, las nueve integraciones con datos de
staging, los demás flujos de escritura y confirmación, y la prueba con una
segunda cuenta de ChatGPT. La cuenta Basic conectada no contiene sesiones,
setups ni notepads. Por tanto, la release continúa privada y preliminar. No se
añade un enlace de instalación a la landing ni se solicita una ficha pública.

## Incidencia OAuth de staging, corregida

El servidor que crea el contexto OAuth es `https://mcp-staging.brakinglab.com`.
El JavaScript publicado en la preview de `apps/app` usa
`https://telemetry-iteration-candidate-staging.up.railway.app` como
`VITE_MCP_SERVER_URL`. Para el mismo contexto reciente, el primero respondió
`200` y el segundo `404`; la preview mostró «solicitud caducada» de inmediato.
La configuración local `.env.preview.local` sí apunta al servidor correcto.

La reconexión se completó sirviendo la misma página de consentimiento en local,
con un proxy temporal para las rutas OAuth hacia el MCP correcto. ChatGPT mostró
la cuenta conectada tras recargar la ficha y la llamada `whoami` funcionó.

Después se corrigió `VITE_MCP_SERVER_URL` para Preview/develop en Vercel y se
redesplegó la app. Tanto `app-staging.brakinglab.com` como la URL de preview de
develop que usa OAuth apuntan al despliegue listo
`dpl_F8psAUwqV68EH7qggezhFzxf99Yq`. El bundle servido desde esa URL contiene
`https://mcp-staging.brakinglab.com` y ya no contiene el host candidato. La
conexión siguió respondiendo a `whoami` tras el despliegue; no se ha repetido
todavía una autorización nueva de extremo a extremo desde esa preview.

Además, el [cambio de consentimiento](https://github.com/r-bart/braking-lab-monorepo/pull/74)
ya integrado en `develop` muestra por separado los scopes `race-engineer:read`
y `race-engineer:write`, en EN/ES, y rechaza un scope desconocido antes de
mostrar el botón de autorización. El bundle publicado contiene ambos textos.
Los checks del PR terminaron verdes, incluidos `lint-and-typecheck`, el job
general `test` y las previews de Vercel.
