# Braking Lab Race Engineer 0.1.0 — piloto privado

Primera versión instalable de las nueve skills compartidas y la conexión al MCP de Braking Lab.

## Archivos

- `braking-lab-claude-0.1.0.zip`: Claude chat y Claude Code, con un conector MCP.
- `braking-lab-chatgpt-0.1.0.zip`: ChatGPT, con la app MCP registrada para el piloto personal.
- `braking-lab-portable-0.1.0.zip`: formato Agent Plugins con `plugin.json` y `mcp.json`.
- `SHA256SUMS`: huellas de los tres archivos.

El repositorio sigue privado. ChatGPT y Claude chat importaron sus archivos y mostraron nueve skills y una conexión cada uno. Claude Code y Codex instalaron desde el repositorio. La autenticación con Braking Lab, las respuestas basadas en telemetría y las operaciones con confirmación siguen pendientes de pruebas de extremo a extremo. El identificador de la app de ChatGPT corresponde al piloto personal y deberá sustituirse durante el proceso de publicación.

Guías: [Claude](https://github.com/r-bart/braking-lab-agent-skills/blob/v0.1.0/docs/install-claude.md), [ChatGPT](https://github.com/r-bart/braking-lab-agent-skills/blob/v0.1.0/docs/install-chatgpt.md), [Codex](https://github.com/r-bart/braking-lab-agent-skills/blob/v0.1.0/docs/install-codex.md) y [otros agentes](https://github.com/r-bart/braking-lab-agent-skills/blob/v0.1.0/docs/install-other-agents.md).
