# Canonical Braking Lab icon

The current public manifest uses `braking-lab-isotype.png` for both `logo` and
`composerIcon`. It is the current orange pedal isotype, with a cream outline,
in a transparent 512 × 512 PNG (9,813 bytes). The provider archives contain this
exact referenced file; `braking-lab-isotype.svg` retains its vector source.

- SVG SHA-256: `b4c79f9a94b4db821848159285fbd62eb95fcf7449ae602e0ce9326aa420f360`
- PNG SHA-256: `b744b0d7bc6bf99501489cde9e5000eb9d1137ccbde42f9289c314d2d10ea5a6`

Earlier `braking-lab-v5` and `icon` files are compatibility assets and are not
the listing assets referenced by the current public manifest.

Updating the icon does not change the production MCP connection or any private
App binding. Private staging packages are built separately and are excluded
from this public upload. A generic host icon does not by itself establish
a problem with the packaged icon or its cache.
